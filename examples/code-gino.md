# My video style

Profile: Code Gino — natural captions and demonstrated effects. Content type: talking-head. Brand: Code Gino.

## Format
- Vertical 9:16, 1080×1920; frame rate: source when practical, otherwise 30; bitrate starting point 5M.

## Language
- Speech: ask for each video. Explicit language in a request overrides this. Never translate.

## Captions and on-screen text
- Speech captions: phrase chunks (only when the video has speech).
- Phrase chunks: 3–6 words, max 2 lines, about 3.0s each; #FFFFFF, 72px.
- Text overlays (titles/labels, not speech): none. Factual overlay text is confirmed with you first.

## Branding
- Branding on. Website: carlogino.com; handle: @codegino.
- Palette: background #102B2D, accent #EFA269, secondary accent #2B8F96, primary text #FFFFFF, secondary text #C4D9D9.
- Intro on (2.5s); outro on (1.8s).

## Hook
- on: truthful title in the first 3.0s, at most 7 words.

## Pace and rhythm
- Pace: natural. Cuts align to: scene. Spoken words are never cut.

## Graphics and effects
- Graphics: balanced. Requested effects are implemented and verified, not just labeled.

## Transitions
- swipe, 0.2s, at least 3.0s apart.

## Color
- warm. HDR is converted to SDR first.

## Audio
- Mix: original. Sound effects on. Music only from tracks you attach or confirm are licensed.

## Delivery
- MP4 + SRT subtitles + editable project ZIP. Nothing is posted or uploaded without a separate request.

## Style reference
- Reference: none. Desired traits: use the settings above.
