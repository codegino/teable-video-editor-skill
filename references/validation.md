# Validation record — portable profiles (profile v2, style schema 2)

Updated 2026-10-18.

## Completed checks

- **51 deterministic tests passed:** 21 media-helper tests, 22 profile tests, 5 v1-migration tests and 3 CLI tests.
- **v1 compatibility.** `scripts/fixtures/` holds v1 profiles generated by the previous release (neutral, Code Gino, a customized landscape/Taglish/single-word profile, a keep-all square profile, and the legacy `my-video-editor` marker), plus the cut plans and caption events that release produced. Migrated profiles must reproduce those EDLs and caption events exactly, both on import and after `migrate` rewrites them as v2 Markdown.
- Profile tests cover sparse round-trips for every format, neutral defaults, content-type presets and their precedence, per-video changes that leave the profile untouched, the structured language setting (codes, mixed speech, legacy names), v1 answer aliases, overrides restricted to tunables (preferences and fixed rules rejected), invalid values and envelopes, caption-off delivery, keep-all planning, and metadata suggestions.
- `examples/code-gino.md` imports to the same resolved settings as the v1 Code Gino preset. No Code Gino identity appears in defaults or new profiles.
- The CLI requires explicit `--style` for planning and captions, and `import` reports in-memory v1 upgrades.

## Changed behavior

- `references/my-style.json` (Code Gino preset doubling as the schema) is replaced by neutral `references/defaults.json` and `references/content-types.json`. Code Gino is now an ordinary example profile.
- Profiles are sparse: user choices plus tunable overrides. Improvements to defaults reach existing profiles; the job's resolved `job-style.json` records exactly what an edit used.
- Fixed rules (preserve speech, no replacement narration, no automatic publishing, codecs, verification) are no longer profile fields and cannot be overridden.
- New preference fields exist in the schema (`content_type`, `text_overlays`, `pace.rhythm`, `audio.mix`, `graphics.mode`, `color.style` warm/cool/neutral). Footage-analysis features that use `rhythm` and the non-speech mixes are not implemented yet; do not describe them as supported.

## Limits

- No new full video was rendered during this update. Passing tests does not establish visual quality, transcription accuracy or browser playback quality.
- The importer validates machine settings, not agreement with human-edited prose. The agent must read both and resolve conflicts.
- The replacement `.skill` must be installed through the supported UI before it becomes the active installed version. A profile update alone does not require reinstalling the skill.
